# Changelog

## 1.3.0

- Added: Legendary Edition search.
- Added: First Shop Voucher search.
- Added: search progress and a seed history file.
- Added: a search time estimate in the Brainstorm tab, based on your own measured speed.
- Fixed: stopping a search with Ctrl+A now removes the Rerolling text.

## 1.2.1

- Added: Rare Tag Joker now lists every Rare Joker, including those added by other mods.
- Fixed: the search stops if the chosen Rare Joker is no longer in the game.

## 1.2.0 (Brainstorm Plus)

First release of this fork, based on Brainstorm v1.1.0-alpha.

- Fixed: auto-reroll uses the game's real tag pool when the Multiplayer mod is installed.
- Fixed: the Soul check stops at the first Soul in a pack.
- Added: Tag Count, First and Second Soul Legendary, Rare Tag Joker.
- Changed: the search pack starts on None.
- Fixed: a second installed copy of Brainstorm no longer loads the mod twice.
